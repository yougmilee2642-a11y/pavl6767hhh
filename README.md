# AD2AD — главная страница

Адаптивная главная страница по [макету Figma](https://www.figma.com/design/r6wHkul4zEFAlJjoLg5n94/?node-id=21-2).

## Запуск

Требуется Node.js 18 или новее. Внешних npm-зависимостей нет.

```sh
npm run dev
```

Открыть http://localhost:4173. Для проверки синтаксиса: `npm run check`.

## Состав

- `dist/index.html` — только главная страница.
- `dist/styles.css` — стили и адаптация под планшеты и телефоны.
- `dist/app.js` — демонстрационный выбор непрерывного периода в декабре 2026, расчёт примерной цены, мобильное меню и информационные диалоги.
- `dist/assets/` — локальный SVG из Figma, шрифт Inter с лицензией OFL и адаптированный логотип пользователя `ad2ad-logo.png`.

Календарь использует пример из макета: 60 BYN в день. Занятые даты и HOLD недоступны. Первый клик выбирает начало, второй — конец свободного периода. Авторизация, реальный каталог, кабинет оператора, отправка заявок и удержание дат сервером не реализованы. Диалоги явно сообщают об этом и не имитируют успешную отправку.

Статический хостинг: опубликовать содержимое `dist/`. Сборка не требуется.
